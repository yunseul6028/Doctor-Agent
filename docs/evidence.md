## 3.4 설정 스위치

README [3.4](../README.md#34-설정-스위치와-비교-실험-조건)에서 옮김.

모든 계층은 환경 변수로 끌 수 있어, 각 계층의 효과를 따로 잴 수 있습니다 (기본값은 모두 켜짐).

| 스위치 | 끄면 없어지는 것 |
|---|---|
| `AGENT_USE_KB` | 지식 베이스 힌트, 다음 행동 추천(지식 베이스 필요), 검토 화면의 성별 제한 경고 |
| `AGENT_USE_GROUNDING` / `AGENT_USE_DANGER_GATE` / `AGENT_USE_PRECONDITIONS` | 근거 확인 / 위험 질환 관문 / 검사 전 안전 조건 |
| `AGENT_USE_TRIAGE` / `AGENT_USE_ANCHORING` / `AGENT_USE_PLANNER` / `AGENT_USE_CONFIDENCE` | 불안정 환자 경고 / 초기 감별 목록·조기 고정 점검 / 다음 행동 추천 / 확신도 되묻기 |
| `AGENT_USE_RESULT_INTERPRETER` | 결과 판독(장부 기록·판독 힌트·위급 경고·관문 연결 전부). 영상 판독 서브 에이전트도 함께 꺼짐 |
| `AGENT_USE_SUBAGENTS` | 전문 서브 에이전트 전부(추가 모델 호출 0). 하나씩은 `AGENT_USE_CONSULT` / `AGENT_USE_ADVOCATE` / `AGENT_USE_LLM_RADIOLOGY` |
| 수치 설정 | `AGENT_CONFIDENCE_PUSHBACK_BELOW`(0.3), `AGENT_MAX_ADVISOR_CHARS`(900), `AGENT_MAX_VIEW_CHARS`(12,000), `AGENT_CASE_TIME_BUDGET_S`(0=무제한), `AGENT_DEGRADE_AT_FRAC`(0.6), `AGENT_FINAL_RESERVE_S`(45), `AGENT_ANCHORING_MIN_TURNS`(5) |
| 서브 에이전트 수치 | `AGENT_MAX_SUBAGENT_CALLS`(3, 증례당), `AGENT_MAX_SUBAGENT_CHARS`(600), `AGENT_CONSULT_MIN_TURNS`(5), `AGENT_CONSULT_MIN_SHARE`(0.6), `AGENT_CONSULT_LOW_CONF` / `_TURNS` / `_AFTER`(0.5 / 3 / 6), `AGENT_ADVOCATE_CONF_BELOW`(0.4), `AGENT_ADVOCATE_ON_ANCHORING`(0=끔), `AGENT_SUBAGENT_TIME_FACTOR`(3), `AGENT_SUBAGENT_REASONING_EFFORT`(low) |

## 5.2 소견 해석 규칙

README [5.2](../README.md#52-해석-규칙)에서 옮김.

| 현상 | 처리 |
|---|---|
| **극성** | 언급 뒤 첫 단서: 부정(없/않/아니/음성/정상/부인…), 긍정(있/양성/관찰/촉지…), 불확실(모르겠/기억이 안 나…). "수 없", "이유 없이" 같은 부정처럼 보이는 관용구는 먼저 가림. "가라앉지 않"은 지속이므로 있음. 이중 부정("없지는 않아요")은 있음 |
| **목록 부정** | "발열, 오한, 기침은 없어요"처럼 맨 끝 부정이 목록 전체를 덮음. 단 "통증 없는 질 출혈"처럼 명사를 꾸미는 부정, "정상 축", 항목마다 자기 서술이 있는 경우는 덮지 않음 |
| **주어** | 주격 조사가 붙은 사람 말("어머니가", "가족 중") → 가족, "남편이", "같이 먹은 동료" → 타인. "가족력:" 머리말, 보호자 대리 응답("(남편) …")도 처리 |
| **시간** | 과거("예전에", "N년 전"), 간헐("가끔"), 만성("N개월째", "복용 중"), 현재. "지금은 괜찮아졌어요"가 붙으면 앞 소견을 과거로 |
| **추측·가정** | "~것 같아요"는 극성 유지(발열 안전 확인은 여전히 작동) + 신뢰도만 낮춤. "혹시 …일까 봐"는 가정 → 불확실 |
| **비유** | "몸이 불덩이 같아요"처럼 의도된 비유 표현만 살리고, "X처럼"의 X는 버림 |
| **수치** | 체온(≥ 37.8 발열), 맥박, 호흡수, 혈압, 산소포화도(혈관·심방 이름이 붙은 포화도는 제외), 핵심 검사 17종(WBC, Hb, 혈소판, Na, K, 혈당, Cr, BUN, AST/ALT, 빌리루빈, 알부민, CRP, ESR, HCO3, INR, 호산구)과 괄호 안 참고치, 요검사 |
| **나이별 활력징후** | 18세 미만은 Fleming 2011 백분위(PMID 21411136)로 판정: 99백분위 초과 → 있음, 90–99 → 불확실 |
| **예/아니요 답** | 질문을 맥락으로 주면 "네/아니요/모르겠어요"가 질문의 개념을 해결 (부정형 질문이면 "네"를 뒤집음) |
